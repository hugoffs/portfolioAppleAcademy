ELLIPTIC APP

Tecnologia: Java Grafo Dados

Neste projeto, desenvolvemos uma aplicação utilizando estruturas de dados em grafos, tendo como base o conjunto de dados de transações de Bitcoin da Elliptic.

O objetivo foi analisar as relações entre as contas e transações para auxiliar na identificação e previsão de atividades potencialmente maliciosas.

Durante o desenvolvimento, aperfeiçoei minhas habilidades de programação e documentação em Java, além de aprofundar meus conhecimentos em estruturas de dados e algoritmos.

Também trabalhei na otimização da aplicação para lidar de forma mais eficiente com grandes volumes de dados.
